# Helm charts for tier L4. One per line:
#   <release> <repo-url-or-oci-ref> <chart> [extra helm args...]
# For an OCI ref, put `-` as <chart>. Versions are left unpinned on purpose;
# the runner records the version it actually installed in results.jsonl.
# Chosen to cover what home/edge clusters typically run: ingress, certificates,
# monitoring, GitOps, operators with CRDs and webhooks, and stateful apps.
# Every chart here passes on the k3d reference. Tried and left out because
# they fail there too: fluent-bit (mounts /etc/machine-id, absent on k3d
# nodes), authelia and immich (need site-specific configuration or an
# existing volume claim), ollama (a multi-GB image does not pull within the
# timeout), sealed-secrets (its Helm repository is gone). Not tried: charts
# that need kernel modules or cloud accounts (longhorn, openebs-lvm, cilium,
# tailscale-operator), and ingress-nginx (retired upstream).
